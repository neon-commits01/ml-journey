# 🏏 IPL Data Analysis

## Overview

Exploratory data analysis of IPL cricket matches using Python and Pandas.

## Dataset

- **Source:** Kaggle — IPL Complete Dataset
- **Files:** matches.csv, deliveries.csv
- **Coverage:** IPL seasons 2008–2019

## Key Findings

- 🏆 Most successful team: **Mumbai Indians**
- 🏏 Top run scorer: **Raina**
- 🎯 Top wicket taker: **SL Malinga**
- 🏟️ Most used venue: **Eden Gardens**
- 📈 Highest scoring season: **2018**

## Questions Answered

1. Which team won the most IPL matches overall?
2. Which batsman scored the most runs across all seasons?
3. Which bowler took the most wickets?
4. Which venue hosted the most matches?
5. Which season had the highest average match score?

## Visualisations

- Bar chart: Top 10 IPL venues by matches hosted
- Line chart: Average match score by season

## Tools Used

- Python
- Pandas
- Matplotlib

## How to Run

```bash
pip install pandas matplotlib
python ipl_analysis.py
```
